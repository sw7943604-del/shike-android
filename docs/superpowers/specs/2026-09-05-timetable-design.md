# 拾课：个人安卓课程表

用户已于 2026-09-05 确认实施。面向一加 13 / Android 16，交付本地 APK。

## 已确认范围
- 原生安卓界面，暖白与石墨黑主题，低饱和课程色，周课表和今日课程。
- 课程保存在设备本地，支持手动编辑、学期起始日和作息设置。
- 导入 XLS/XLSX、Word、PDF；任何识别结果先预览和校对再保存，缺失教师不阻止导入。
- 中南大学门户登录由用户在手机完成，读取本人课表；不保存密码，不上传文档。
- 今日课程和下一节课桌面组件，与本地课表共享数据。

## 已观察规则
- 本科教务路径 /jsxsd/xskb/xskb_list.do；完整 HTML 表格有教师、地点、周次。
- 网站教学周从周日开始。2026-2027-1 第1周为 2026-09-06 至 09-12。
- 文件每行是星期、每四列合并为节次块；一个块可含多课，使用横线分隔。
- 支持 1-9,12-18周、11-18单周，同名课程在不同上课时间/地点不能误合并。
- 实践课仅周次缺少节次时作为待补充事项，不猜测日期。
- XLS 附有第1—10节作息，第11—12节未提供，不猜测。

## 技术边界
Java 原生 Activity / View；minSdk26、targetSdk36；小组件 RemoteViews。纯 Java 排课模型与解析器可独立 JVM 测试。文档先本地提取，扫描 PDF 用中文 OCR，失败明确提示并可手工录入。网页只向学校白名单站点开放读取，不绕过认证或证书错误。

## 验收
真实 XLS 能形成与源文件一致的课程块；单双周和跨年日期有测试；导入不直接覆盖；重启后数据保留；APK能构建并签名验证；设备验证区分模拟器与用户真机。
